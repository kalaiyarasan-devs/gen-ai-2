# GenAI Image Captioning

## 📌 About the Project
GenAI Image Captioning is an AI-based application that automatically generates meaningful text descriptions for images. It uses a pre-trained vision-language model to understand the contents of an image and produce a caption in natural language.

## 🎯 Objectives
- Generate captions automatically from images.
- Understand image contents using AI.
- Explore Generative AI and computer vision.
- Build an easy-to-use image captioning application.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **AI Platform:** Hugging Face
- **Model:** Salesforce BLIP Image Captioning
- **Libraries:** Transformers, PyTorch, Pillow
- **Interface:** Command Line / Streamlit (optional)

## ✨ Features
- Upload or select an image.
- Generate a natural-language caption.
- Support common image formats such as JPG, JPEG, and PNG.
- Use a pre-trained AI model without training from scratch.
